# نغماتي — منصة الفنون الموسيقية (سلطنة عُمان)

موقع ثابت (HTML/CSS/JS) بدون build وبدون تسجيل دخول. المحتوى الرسمي مأخوذ من دليل المعلم.

## النشر
- **GitHub Pages:** Settings ← Pages ← Source: **GitHub Actions**. ثم أي push على `main` ينشر تلقائيًا.
- **Netlify / Cloudflare Pages:** Publish directory = `.` وبدون build command.

## الهيكل
- `data/curriculum.json` — محتوى الصفين (الأول من الدليل، الرابع قيد الإعداد)
- `js/app.js` + `js/lab.js` — الواجهة والمختبر
- `css/style.css` — التصميم
- `img/ — صور الواجهة (webp)` — الشخصية

## ملاحظات
- التمارين الإضافية والمختبر معلّمة "إضافي" وليست من الدليل.
- روابط QR في الدليل لم تُستخرج بعد (أرقام صفحاتها في وضع المعلم).

## إضافة فيديوهات يوتيوب
افتحي `data/videos.json` وضعي رابط اليوتيوب بين علامتي التنصيص بجانب الدرس، مثال:
`"grade-1/l1-1": "https://www.youtube.com/watch?v=XXXXXXXXXXX"`
(مفاتيح الدروس: `grade-1/l1-1` … `grade-4/l4-3`). الفيديو يظهر تلقائيًا فوق شخصية المعلم في الدرس، وإذا تُرك فارغًا لا يظهر شيء.
